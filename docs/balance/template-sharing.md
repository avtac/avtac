# Template Sharing

Sharing templates can be done simply by sending a copy of your template to someone.
They upload the config to their browser and they get access to your template.

But what happens when you share the file to 10 people, and you update it. Or you
want anyone at a flight school to be able to use the template.

This is where the Template Browser comes into play. You can browse templates
that other people have uploaded and try them out for yourself.

## Template Browser

The Template Browser is access on the export page. It displays a list of available
templates that users have uploaded. It includes a search bar and the ability to
sort by likes, downloads, and age both ascending and descending. Liked templates
will always be displayed first.

Navigate through the pages with the arrow keys on the bottom and click on any
row to view the details.

Viewing the details will show the version and date the file was uploaded. Followed
by the available user inputs, expected limits, and expected regions. At the bottom
a SHA256 hash can be used to ensure the file's contents where not modified.

To the right files can be downloaded, added, and liked. Downloading saves the file
to the computer and adding imports the file into the app.

## Uploading Files

Uploading a file can only be done with a valid API key. This can be generated by
clicking the `Generate Key` button in the top right corner.

> [!Important]
> When generating a key, it will display on screen. Ensure you save this somewhere
> save. Losing it would result in losing all modification access to uploaded files.

If a key becomes compromised a new key can be generated by selecting `Generate Key`
and entering your current key. Generating a new key will revoke the current one
and move file access to the new key.

### Tagging

Tagging files allows for easier search of files. Add tags in the details page of
owned files. Tags are version specific so updating the version will require adding
new tags.

### Versions

Multiple versions of a file can be uploaded. This is to provide a way to update
files without losing the history of previous versions.

Upload a new file by clicking the upload button on the details page of any owned
file. Once uploaded the version should increment and clicking on the version will
allow you to switch between versions.

### Deleting Files

It is possible to delete files. This is done by clicking the trashcan button on
the details page of any owned files. This will delete the currently selected version.

> [!Warning]
> Deleting all versions of a file will result in the loss of all download and like
> history for that file.
